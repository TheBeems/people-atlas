- Target version: `0.11.0`.

## Scope

1. Change only the declared version authorities to `0.11.0`: `package.json`,
   `manifest.json` and an add-only `versions.json` entry. Do not change
   dependencies or `package-lock.json`.
2. Raise the release-contract bundle limit to `BUNDLE_LIMIT_BYTES = 500_000` in
   `scripts/release-contract.mjs` as a deliberate contract adjustment; the
   production `main.js` is ~417 KB and within the new limit.
3. Add accurate English `0.11.0 (Alpha)` changelog and release-note copy
   covering the multilingual UI (EN/NL), locale-aware formatting, and the
   increased bundle limit.
4. Commit the complete verified product, evidence and release-preparation
   worktree on `main`, verify remote commit CI, then create and push the
   annotated `0.11.0` tag.
5. Let the existing tag workflow publish and attest the three assets; do not use
   `gh release create` or manually upload assets. After workflow success, set
   the release title and prerelease state with `gh release edit`, then verify
   tag provenance, release metadata, assets, downloaded hashes and attestation.
6. Close this ticket only in a separate docs-only follow-up commit after all
   remote evidence is verified; that closure commit must not move tag `0.11.0`.

- Product/test/dependency/lockfile/workflow changes beyond the already reviewed
  current worktree and the versioned release copy.
- Obsidian Community Plugins submission or manual asset uploads.
- Claiming unperformed live Obsidian Desktop, Bases, pop-out,
  assistive-technology or Mobile validation.
