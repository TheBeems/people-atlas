# People Atlas

People Atlas is een opzet voor een moderne Obsidian 1.13+-plugin waarmee personen, relaties en onopgeloste contacten in een vault in kaart worden gebracht.

De basis bevat al een zelfstandige view, een Bases-view, declaratieve instellingen, een incrementele index, stabiele personen-ID's, expliciete relatienotities, wikilink-resolutie, canvasweergave, diagnostiek en tests.

## Starten

```bash
npm install
npm run dev
```

Plaats of symlink de map in:

```text
<Vault>/.obsidian/plugins/people-atlas
```

Herlaad Obsidian en schakel **People Atlas** in bij Community plugins.

De voorbeeldnotities staan onder `examples/`.

Een direct kopieerbare pluginmap staat onder `release/people-atlas/`.
